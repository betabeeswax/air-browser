PasswordsImport or export a password CSV from Chrome, Edge, or another password manager. Imported passwords are encrypted for this Windows user on this device.
Step-by-step: import passwords from Edge or Chrome
  1. Open Edge or Chrome and go to its Password Manager.
  2. Open Settings in Password Manager and choose Export passwords.
  3. Save the CSV file somewhere private on your PC.
  4. In AIR Browser, open Settings → Import & export → Import CSV.
  5. Select the CSV file. AIR encrypts imported passwords for your Windows account on this device.
  6. Delete the exported CSV when you are finished. It contains readable passwords.
