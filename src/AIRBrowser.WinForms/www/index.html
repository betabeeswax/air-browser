Import & export

Bring your bookmarks and saved passwords into this AIR profile.

BookmarksImport HTML bookmarks from Chrome, Edge, Firefox, or a JSON export. Export as a browser-compatible HTML file.
PasswordsImport or export a password CSV from Chrome, Edge, or another password manager. Imported passwords are encrypted for this Windows user on this device.

CSV exports contain readable passwords. Keep them private and delete them after importing. AIR Sync will need an account-level encryption setup before passwords can safely sync between devices.
