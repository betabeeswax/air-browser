# AIR Browser

**A clean, simple, privacy-focused browser**

Official website: **https://air-browser-rha-nine.vercel.app**

## Download the Windows EXE

1. Go to **[Releases](https://github.com/betabeeswax/air-browser/releases)**
2. Download **AIR-Browser-Portable.exe**
3. Double-click to run (no install needed)

Builds start automatically on every update.

---

## Features

- Custom AIR Start Page with widgets
- Dark mode by default (black + blue)
- Multiple Profiles with different search engines
- Tab Groups, Bookmarks, Export/Import
- Your data stays on your device
