System requirements

  • Windows 11
  • 64-bit (x64) computer
  • Internet connection for websites
  • About 200 MB of free space recommended

AIR Browser currently targets Windows 11 x64. The portable app download is a ZIP containing AIRBrowser.WinUI.exe and its required files. Extract it, then open AIRBrowser.WinUI.exe; it is not a single-file EXE.

Code signing & download safety

Verified AIR Browser downloads

AIR Browser is applying to use the SignPath Foundation for free code signing of eligible open-source releases. Signing will only be enabled after the project is accepted and the signing workflow is configured. Until then, downloads may be unsigned and Windows may show a security warning.

Always download AIR Browser from this page or the official GitHub Releases.

Good to know

Questions & answers.

Is AIR Browser free?

Yes. The project is open source and Windows builds are published through GitHub Releases.

Does AIR Browser need an account?

No AIR account is required for local browsing. AIR account sync and Microsoft/Google integrations are planned; cloud sync is not active in this first native build.

Where are my bookmarks and settings?

They are saved in the browser's local profile folders. Cloud sync and backup controls are planned follow-up features.

Can I use it on Android, macOS or Linux?

Not currently. The published desktop build is for 64-bit Windows. Other platforms may be considered later.

Windows says the app is unrecognized. What should I do?

Only download AIR Browser from this project's official GitHub Releases page. Windows SmartScreen warnings can appear for new or unsigned apps. Do not run a file if you are unsure it came from the official release.

Where can I report a problem?

Open the GitHub repository and create an issue with what happened, what you expected and any error message. Do not include passwords or private browsing information.
