AIR Browser

A clean, simple, privacy-focused browser with profiles, widgets, tab groups, and easy data export.

Download ZIP View on GitHub

Features

Multiple Profiles

Each profile can have its own search engine (Bing, Google, DuckDuckGo, Brave).

Custom Start Page

Add and remove widgets like Weather, Clock, Notes, and Quick Links.

Tab Groups

Organize your tabs into colored groups for better focus.

Bookmarks & Export

Save bookmarks and export/import all your data easily.

Dark Mode by Default

Clean black + blue theme that matches the AIR style.

Private by Design

Your data stays on your device. No accounts required.
